# Structural IS Code RAG Pipeline for AI-Driven 2D CAD Design

Production-grade Retrieval-Augmented Generation (RAG) pipeline for structural Indian Standards (IS Codes) to enable AI-driven, IS-compliant 2D CAD design generation.

## Current Setup & Working Scope
- Target Code: IS 456:2000 (Plain and Reinforced Concrete) - *Working assumption*
- Initial Component: Reinforced Concrete (RC) Beam - *Working assumption*
- Active Tooling: Python 3.11, PyMuPDF
